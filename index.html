Falta conectar o banco de dados

Pra salvar os portais, preencha as credenciais do Supabase no arquivo config.js.

  1. Crie um projeto grátis em supabase.com.
  2. No painel do projeto, abra Project Settings → API e copie a Project URL e a chave anon public.
  3. No SQL Editor, rode o conteúdo de schema.sql (cria a tabela e as permissões).
  4. Cole a URL e a chave no arquivo config.js e faça o deploy.

O passo a passo completo está no README.md do projeto.
